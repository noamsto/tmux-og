# Bridge: open crew dash as a tiled side split in mirror windows (#1196)

`tmux-crew-dash --side` in a `@bridge_win` mirror window sends the `tool ... crew-dash` verb, which can only create a remote float, and tells the user so. This plan adds a tiled side shape to the daemon's `tool` verb so a mirrored dispatcher gets the same side panel as a local one.

## Design decisions

- **Shape selector: a new tool key `crew-dash-side`**, not an extra shape argument. The verb's arg contract (`args: 1, optArgs: 1`: tool, optional dir) is untouched, so every existing caller builds byte-for-byte what it builds today. A daemon older than this change answers `tool: unknown tool "crew-dash-side"`, which is exactly the error the launcher needs to detect and fall back on; an extra shape argument would instead die with `wants 1 argument(s)`, a message tied to arity wording. `crew-dash-side` joins `remoteTools` (the closed authorization set), so the socket peer still cannot smuggle a name.
- **Sizing and fallbacks are computed on the remote in tmux formats**, in the `if-shell -F` condition and in `split-window -l`, so they follow the remote's real window/pane width rather than the mirror's. Probed on next-3.9: `split-window -l` format-expands (`-l '#{?#{e|<:X,50},50,#{?#{e|>:X,80},80,X}}'` gave 64 / 50 / 80 columns for windows 200 / 100 / 300 wide, with X = `#{e|/:#{e|*:#{window_width},32},100}`).
- **Fallback is the existing float**: when the remote pane is floating, the remote window is `@crew_grid 1`, or `pane_width < width + 81` (target kept at 80 columns plus 1 separator), the else-branch is the unchanged float command for `crew-dash`. This mirrors the local `open_side` fallbacks (floating target, grid, too narrow).
- **Mirror reconcile needs no change.** The verb carries `layout: true, moves: true` exactly like `split-h`, which already creates a remote tiled pane that the reconcile mirrors via the remote layout string (`reconcile.go` select-layout from the remote's `window_layout`); widths follow the remote layout. This is verified by reading `reconcile.go` and by the real-tmux Go test below asserting the remote pane widths; no reconcile test is added unless Step 6's read finds a gap.
