## Residuals (PR body)

- Pre-#783 raw-named mirrors never reopened keep their name until reopened/detached/closed; a tmux-remux ghost from an old snapshot likewise (spec non-goal).
- For a `##` name the old daemon's sock (built from the unexpanded `h-x##(y)`) equals the new mirror's sock path; if the old daemon's ownership cannot be proven it is not signalled, and the new daemon rebinds the same path — the same kind of same-path recreate the launcher already does today.
