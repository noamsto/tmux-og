# Window picker: place a remote window into the current session (#1106)

Enter on a Remote-section **window row** in `prefix + w` places that one remote window into the session the picker was opened from, as a placed mirror (`og-remote-open <host> <sess> --into <cur> --window @N`) and selects it. `ctrl+e` keeps today's behaviour (dedicated mirror session focused on that window). The wall (`prefix + W`) is untouched.

## Decisions

- **Modifier key: `ctrl+e`.** shift+enter / ctrl+enter could not be measured end-to-end here (no scripted harness could drive a popup on a pty client), so no claim is made that they survive tmux; `extended-keys on` + `csi-u` is set in the config but unverified inside a `display-popup`. `ctrl+e` is free (used ctrl keys: a c g j k o s t x) and needs no extended keys. The PR says so.
- **Current session** = the session of `OG_PICKER_CURRENT_WINDOW` (already exported by `tmux-window-picker.sh`), resolved by id: `tmux display-message -p -t <@id> '#{session_id}|#{session_name}|#{?#{@bridge_placed},,#{@bridge_host}}|#{?#{@bridge_placed},,#{@bridge_sock}}'` (the `@bridge_placed` gate stops a placed mirror window's window-scoped stamps from reading as a dedicated session, as `bridgeSessionFormat` does; otherwise sitting on a placed window would redirect every later Enter) (field-delimited with `|`, per repo rule). Seamed as `currentSessionFn` for tests. No current window (env empty) or a failed lookup → fall back to the dedicated open, today's behaviour.
- **Current session is a dedicated mirror** (`@bridge_host`/`@bridge_sock` non-empty): the launcher refuses `--into` there (the daemon kills its session on teardown, placed windows included). **Redirect to the dedicated open** of that window: the user asked to see the window, and the dedicated open is exactly what ctrl+e does. Decided in `placeDecision`, not by waiting for the launcher's refusal.
- **Already placed in the current session**: focus it, no launcher. Detected with one `tmux list-panes -s -t <session_id> -F '#{window_id}|#{@bridge_placed}|#{@bridge_host}|#{@bridge_session}|#{@bridge_pane}'` read: a row with `@bridge_placed=1`, same host and session, and `@bridge_pane` equal to the remote window's pane id. The remote probe row gains the window's active pane id (`#{pane_id}`, inserted before the name so the name stays last), stored as `remoteWindowPane` on the row; a cached row has none (`json:"-"`, copied in `remoteWindowRowItem`), so it skips the check and relies on the launcher (same selector, same session = same lock key = live daemon, exits 0 without a duplicate), then selects by the same lookup if a pane id exists, else just closes.
- **Placed in another session**: not a conflict; a second placed daemon is keyed by local session id, so it places another copy here. **Its remote session already has a dedicated mirror**: such a session's windows are never listed as remote rows (`bridgeSessionPresent` in `remoteWindowsForHost`/`cachedRemoteWindowRows`); the user reaches them through the mirror's local rows. Documented, pinned by a test that a bridged session yields no window rows.
- **Select after success**: `attachOK` for a placed open runs `select-window -t <local @id>` (found with the same pane lookup, after the launcher returns) then quits. Not found: quit without selecting (the window exists; the status bar shows it).
- **needs-auth / unreachable / cached**: unchanged. Those states live on the host row (Enter there is untouched); a window row under them keeps today's route through the launcher, whose error lands in the status line as `<label>: <msg> — enter to retry`.
- **`^t` marks**: window rows are not markable today (`markable` excludes `remoteWindowID != ""`) and `markedRemoteItems` resolves only session rows. Marks stay session-mode only; unchanged. Enter with marks never reaches a window row in window mode.
- **Spinner / cancel / rollback**: the placed open rides the same `attachSpec`/`attachRun` supervision, but the launcher closes the progress fd after `mirror` and then waits up to 60s for the daemon to listen, while the picker's `phaseMirror` budget is 15s; a placed spec therefore gets a 60s `phaseMirror` budget (set on the run's budget map). `attachState` gains `placed bool`, `localSession` (id), `remotePane`, `host`/`sess` for the post-success lookup. Otherwise the same supervision (spinner phases from the launcher's progress fd, esc/ctrl+c cancel, TERM→KILL of the process group). The launcher's `--into` path has its own lock, refusals and error text; stderr becomes the status line like any attach failure. No new rollback: a placed open never creates a session.

## Steps

1. `picker/attach.go`: `attachSpec` gains `into string` (local session name) and `selector string`. `buildAttachCmd` emits `host sess --into <into> [--window <selector>]` when `into != ""` (and never appends the positional `window` then; the launcher rejects both). A placed spec ignores `restore`/`newDir` (the launcher refuses those with `--into`); the builder never sets the env for them in that case.
2. `picker/remote_wins.go` (also fix the comment at line 25, `remote_wins_test.go:107` format assertion and the 5-field fixtures at :23-29/:62; add cases: name containing `|` after the pane field, missing/invalid pane id): `remoteWindowRowsFormat` becomes `W|#{session_id}|#{window_id}|#{window_index}|#{pane_id}|#{window_name}`; `parseRemoteWindowsOutput` reads the pane id (validated `%N`; absent/invalid keeps the row without it); `remoteWindow`/`listItem` carry `remoteWindowPane` (not cached: `json:"-"`).
3. `picker/tui.go`: new `placeRemoteWindow(item)` and `placeDecision(item) (action, sessName, sessID)`: pure given the injected lookups; returns `placeFocus{localWindow}` / `placeOpen` / `placeDedicated`. `activateCurrent`: for a window row (`remoteWindowID != ""`, not emit mode), consult `placeDecision`; `placeOpen` → `beginAttachPlaced` (builds spec through the existing `beginAttach` path: factor the spec construction so ctrl+e and Enter share it; the placed variant sets `into`/`selector=@N`). New key `ctrl+e` → `activateDedicated` (today's `beginAttach(item, nil)`) for window rows only; elsewhere a no-op.
4. `finishAttach`: for a placed attach, on `attachOK` look up the placed window and `switch-client`/`select-window` it before `tea.Quit` (seamed `selectWindowFn`).
5. `picker/render_list.go`: on a remote window row show `enter:place` and `^e:jump` in the footer; other rows unchanged.
6. Tests (also: placed-mirror current window in a local session still yields the placed argv; ctrl+e is a no-op in wall mode; `picker/tui_attach_test.go`, `remote_wins_test.go`, `render_list_test.go`): Enter on a window row with a current window → fake launcher receives `lab api --into <name> --window @4`; ctrl+e → `lab api @4` (both through `buildAttachCmd`); no current window → dedicated argv; current session is a mirror → dedicated argv; already placed → focus, launcher never runs; failed lookup → dedicated; launcher error → status line; ctrl+e on a non-window row is a no-op; footer shows both hints; probe format round-trip with pane id. Update existing window-row tests that pass `enter` expecting `lab api @4` to set no current window.
7. Bats (`tests/remote-cold-start.bats`, next to the `into: --window` cases at ~1975, same fake tmux/ssh harness): the picker's exact placed argv (`<host> <sess> --into <current-session-name> --window @4`) run against the real `og-remote-open.sh`; assert it is accepted, launches one daemon with `OG_DAEMON_INTO` the current session's id and `OG_DAEMON_SELECT=@4`, and a second window id launches a second daemon (selector names exactly the chosen window). The picker side (key → argv) is covered by the Go tests in step 6 through the same `buildAttachCmd`.
8. Docs: `docs/agents/picker.md` (also the row contract at :233; record that stale cached `@N` ids can hit a different window after a remote restart and that a cached row can duplicate beside a whole-session placement; record the live check that `@bridge_pane` is stamped before the launcher returns) (window-mode Remote section: Enter places, ctrl+e jumps, edge cases above, ctrl+e measurement note), `docs/agents/scripts.md` if the launcher row's caller list changes, README picker blurb if it describes Enter.
9. Gate: `nix build .#default --accept-flake-config`, `nix flake check`, `nix build .#lint --accept-flake-config`.
